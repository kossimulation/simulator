# Simulink-моделі

Файли `.slx` кладіть сюди. Назва моделі стає назвою C++ класу та папки в
`native/generated/`, тому використовуйте `snake_case` без пробілів
(наприклад, `heli_rotor`, `fw_aero`).

## Контракт інтерфейсу для моделі сил і моментів

Щоб модель можна було підключити як `VehicleModel` у C++ ядрі, її
кореневі порти мають бути такими (усі `double`, одиниці SI, радіани):

| Inport          | Опис                                        |
|-----------------|---------------------------------------------|
| `u`, `v`, `w`   | швидкість відносно повітря, зв'язані осі FRD, м/с |
| `p`, `q`, `r`   | кутові швидкості, рад/с                     |
| `phi`, `theta`, `psi` | кути Ейлера, рад                      |
| `altitude`      | висота, м                                   |
| `rho`           | густина повітря, кг/м³                      |
| `throttle`      | газ / загальний крок, [0, 1]                |
| `pitch`, `roll`, `yaw` | органи керування, [-1, 1]            |

| Outport         | Опис                                        |
|-----------------|---------------------------------------------|
| `Fx`, `Fy`, `Fz`| аеродинамічна та тягова сила, зв'язані осі, Н |
| `L`, `M`, `N`   | моменти відносно ЦМ, Н·м                    |

Силу тяжіння й контакт із землею додає ядро, тому в модель їх **не
включайте**. Крок моделі: `sim_dt` (0.005 с), задається в `startup_simulator.m`.

## Робочий процес

```matlab
startup_simulator          % шляхи + параметри fw, heli, sim_dt
open_system('heli_rotor')  % розробка / перевірка в Simulink
generate_code('heli_rotor')% C++ -> native/generated/heli_rotor
```
